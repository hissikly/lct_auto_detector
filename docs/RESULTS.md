# Результаты и границы оценки

## Выбранная модель

- DINOv2 ViT-L/14, вход 336×336, нормированный CLS-вектор 1024D FP32.
- Joint organizer train + CityFlow train; strong augmentation.
- 20 эпох × 335 шагов, best epoch 19; seed 20260918.
- Balanced batch: 4 ID CityFlow + 4 ID организатора, по 4 фото; batch 32.
- Last four blocks + final norm; AdamW; backbone LR 1e-5, head LR 3e-4,
  weight decay 0.04, warmup 2 эпохи; CE с label smoothing и within-source
  batch-hard metric loss.
- Batch AQE k=5, alpha=0.25 и отдельный boosting refusal.

ранних экспериментах; его нельзя описывать как ни разу не открытый за всю
историю проекта.

## FP32 cross-camera retrieval

| Выборка | Метод | mAP | Rank-1 | Rank-5 |
|---|---|---:|---:|---:|
| Dev | Strong cosine | 74,0484% | 74,2581% | 87,9917% |
| Dev | Strong + AQE | 77,6310% | 77,0186% | 87,1636% |
| Calibration | Strong cosine | 81,3685% | 83,7460% | 92,1421% |
| Calibration | Strong + AQE | 84,6474% | 84,8224% | 93,4338% |

Парный vehicle-ID bootstrap для AQE−cosine: dev mAP +3,5826 п.п.,
95% CI [+2,4957; +4,7173]; calibration +3,2789 п.п.,
95% CI [+2,1468; +4,5220]. Dev Rank-5 при этом −0,8282 п.п.
Интервалы не устраняют влияние повторного выбора решений по dev/calibration.

AQE: `normalize(0.75*z + 0.25*mean(top5_neighbors(z)))` для запросов и
галереи совместно. Это transductive-протокол: векторы галереи зависят от
всего набора запросов. Такой результат не является оценкой одиночного
онлайн-поиска.

## Отказ и ограничения

На отдельном open-set dev протоколе strong+AQE+boosting: pair-F1 57,1332%,
query-F1 69,3122%, TNR 78,0600%. Это другое query/gallery разбиение;
его показатели не объединяются с cross-camera mAP в одну метрику.
AQE не показал существенного улучшения F1 относительно strong cosine с
той же политикой отказа.

- Hidden score неизвестен; призовое место не заявляется.
- Итоговый вес — 1 217 580 060 байт; SHA256 в model manifest.
- Реальный smoke 10 gallery + 2 query завершён в сентябре. Полный
  strong-экспорт 750+1110 был остановлен и не считается проверенным.
- Exact AQE имеет квадратичную стоимость. ANN-демо с синтетическими
  отвлекающими векторами не доказывает качество на миллионе реальных авто.
- Скорость на оборудовании жюри, p95 и peak RAM для целевой нагрузки неизвестны.
