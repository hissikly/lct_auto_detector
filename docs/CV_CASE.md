# Кейс для резюме

**Vehicle ReID · ML Engineer · командный проект ЛЦТ 2026**

Разработала ML-пайплайн поиска автомобилей между камерами без OCR:
дообучение DINOv2-L/14, 1024D-эмбеддинги, пакетное AQE-переранжирование
и политика отказа на основе градиентного бустинга. На внутреннем
cross-camera dev наборе достигнут mAP 77,63%; AQE добавил 3,58 п.п.
к выбранному cosine-baseline. Подготовила версионированный inference-bundle
и интеграцию в FastAPI-сервис с одиночным/пакетным поиском и экспортом.

**Стек:** Python, PyTorch, DINOv2, NumPy, pandas, scikit-learn, FastAPI,
Docker Compose, SQLite.

Укороченный вариант:

> Дообучила DINOv2-L/14 для cross-camera Vehicle ReID; реализовала batch AQE
> и отказ от сомнительных совпадений. Внутренний dev mAP — 77,63%
> (+3,58 п.п. от AQE); интегрировала ML-пайплайн в FastAPI-приложение.

Для собеседования: проект командный; метрика внутренняя, hidden score
неизвестен; AQE transductive и относится к пакету запросов. Не добавлять
утверждения о победе, production SLA или миллионе реальных машин.
